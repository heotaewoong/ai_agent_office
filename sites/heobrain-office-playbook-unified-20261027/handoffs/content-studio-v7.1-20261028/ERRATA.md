## 감사 이후 앱 변경 (49dcba9)

- Windows 기본 음성의 WSL 경로 변환을 지웠다. Windows가 아닌 환경에서 Windows 기본 음성을 고르면 오류로 멈춘다. Linux(EC2)에서는 gemini-kore 같은 유료 음성 프로필을 선택해야 한다. 한국어 폰트는 fonts-nanum 같은 TrueType(.ttf)이어야 하며 Noto CJK의 TTC는 PDF 생성기가 읽지 못한다.
- Windows 실행기는 긴 경로 설정이 꺼져 있으면 99자를 넘는 상태 폴더를 거부한다. 산출물 경로가 Windows 경로 한계 260자를 넘는 것을 막기 위해서다.
- 백엔드 테스트는 한국어 Windows 기본 인코딩(cp949)에서도 UTF-8로 읽고 쓴다. FFmpeg가 없거나 symlink 권한이 없으면 해당 테스트는 이유를 남기고 건너뛴다.
- 자세한 실행 조건은 apps/content-office/README.md의 Windows와 Linux(EC2) 절에 있다. 실행 위치는 이 스냅샷 162행의 "개발 EC2, 제작 앱 Windows, WSL 운영 종료"와 같다.

## 사용 시 주의

- **다운로드 ZIP**: 저장소 .gitignore가 모든 ZIP을 제외하므로 dist의 인계 ZIP·소스 ZIP은 커밋돼 있지 않다. 화면을 미리 볼 때는 editable-source/README.md 순서대로 생성기를 먼저 실행한다. 생성 전에는 화면의 ZIP 링크가 열리지 않는다.
- **Windows 출력 글자 깨짐**: 한국어 Windows 콘솔에서 생성기 마지막 요약의 한글이 깨져 보인다. 만들어진 파일은 UTF-8로 정상이다. `PYTHONUTF8=1`을 켜고 실행하면 요약도 정상으로 나온다.
- **OFFICE_INDEX.md**: 루트 .gitignore가 의도적으로 제외하는 로컬 문서다. 저장소에서 받을 수 없으므로 각 작업 PC의 원본을 확인한다.

## 공개 저장소 주소 검토

저장소는 로그인 없이 GitHub API로 조회되는 공개 저장소다. 스냅샷에 든 주소를 확인한 결과 조치가 필요한 항목은 없었다.

- chatgpt.site 안내 주소는 로그인 없이 열면 401로 막힌다. 주소만으로 내용이 공개되지 않는다.
- Vercel 미리보기 주소에 든 계정 이름은 이미 공개된 GitHub 계정 이름과 같다.
- API 키·토큰·비밀번호 값과 로컬 절대 경로는 없다.

## 이 정오표 작성 시 검증

임시 사본에서 editable-source를 다시 실행했다. 원가 검산 19개와 계약·링크·해시 검증 209개가 통과했고, 다시 만든 31개 파일은 커밋된 파일과 바이트 단위로 같았다. 실제 모델 생성·유료 호출·게시·발송은 하지 않았다.
