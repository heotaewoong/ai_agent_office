## 3. 시험 시작 전 고정할 입력

1. `evaluation_id`, 작성자, 승인자, 시험 목적, 모델/공급자/계정 경로, 소프트웨어 버전과 날짜를 정한다.
2. 아래 대본·샷·발음 허용형과 평가 기준을 먼저 고정한다. 결과를 본 뒤 유리하게 기준을 바꾸지 않는다.
3. 소유권이 확인된 절차형 도형·빈 제품 모형·직접 만든 배경을 참조 자산으로 사용한다. 유명인 얼굴·타사 썸네일·특정 작가 스타일·고객 개인정보를 입력하지 않는다.
4. 참조 자산의 파일 해시·색상·비율을 고정한다. 첫 비교 모델이 만든 가장 잘 나온 이미지를 공통 기준으로 쓰지 않는다.
5. API 생성 가능 여부, 이용 권리, 비용 상한, 사람 승인 상태를 먼저 검사한다. 승인 예산이 없으면 `not_run_awaiting_budget`로 기록한다.
6. Midjourney는 자동 요청 대상에 넣지 않는다. 수동 자산을 비교할 때도 제작 시간·선택 과정·비용을 따로 기록한다.

## 4. 공통 중립 한국어 대본

다음 대본은 특정 모델·회사·실제 상품의 우수성이나 성과를 주장하지 않는 시험용 글이다.

> 오늘은 흩어진 자료를 한 편의 콘텐츠로 정리하는 과정을 살펴봅니다. 먼저 출처를 확인하고, 핵심 주장을 원고에 연결합니다. 검토가 끝나면 장면과 자막을 만들고, 마지막으로 사람이 확인합니다. 이 영상의 수치와 물건은 품질 시험을 위한 가상 예시입니다.

- 원문을 모든 후보에 동일하게 사용한다. 모델명·혜택·가격·매출 사례를 추가하지 않는다.
- 대본 길이만 보고 영상 시간을 확정하지 않는다. 실제 승인된 음성 파일의 길이와 단어 시간을 기준으로 장면을 배치한다.
- 같은 원문으로 블로그 요약·뉴스레터·짧은 영상 설명문을 비교하더라도 채널별 허용 길이는 별도 조건으로 둔다.
- 본문이 승인되지 않았으면 영상 생성 단계로 넘어가지 않는다. 영상 검토 완료와 외부 발행 승인도 분리한다.

## 5. 같은 세 샷으로 이미지·영상 비교

### 고정 규칙

- 비식별 도형과 가상 물건만 사용한다. 참조 자산은 모델 시험 전에 직접 제작·승인해야 하며 이번 문서에서 생성한 것은 아니다.
- 공통 관찰용 장면은 16:9로 한다. 가로·세로 콘텐츠는 그 다음 별도 레이아웃 시험에서 확인한다.
- 모델 고유 해상도·FPS의 원본과 비교용 정규화 파일을 모두 보존한다. 업스케일·보간 결과를 원본 품질로 표시하지 않는다.
- 초기 탐색은 모델별 각 샷 2회로 제안한다. 작은 표본이므로 일반적인 품질 우승이나 통계적 신뢰를 주장하지 않는다.
- 같은 샷이라도 모델마다 유효한 길이 파라미터가 다르다. 최종 관찰 구간은 5초로 통일하되, 공급자가 5초 요청을 지원하지 않으면 가장 가까운 유효한 5초 이상 길이로 생성하고 처음 5초를 별도 편집본으로 만든다. 예를 들어 Veo 경로는 6초 요청 후 5초 관찰본을 만들 수 있으나 실제 과금은 6초 기준으로 기록한다. 지원 길이는 호출 직전 스키마로 재확인한다.

| 샷 ID | 공통 장면·지시 | 이미지 기대 출력 | 영상 기대 출력 | 중대 실패 |
|---|---|---|---|---|
| S01 색·형태 일관성 | 밝은 무광 책상에 파란 큐브 `#1F6FEB`, 주황 구 `#F59E0B`, 회색 원통 `#94A3B8`을 왼쪽부터 배치. 로고·글자·사람 없음 | 정확히 세 물체, 지정한 상대 배치·색·형태, 물체끼리 겹치지 않음 | 고정 카메라. 큐브만 천천히 회전하고 구·원통은 제자리에 유지 | 물체 증식·소실, 색이 다른 물체로 이동, 원통이 사람/문자로 변함 |
| S02 가림·이동 | 단순 초록색 장난감 수레가 회색 기둥 왼쪽에 있고, 소유권이 확인된 중립 배경. 사람·문자 없음 | 수레와 기둥의 크기·상대 위치가 참조와 일치 | 수레가 왼쪽→오른쪽으로 이동해 기둥 뒤에 가렸다가 같은 모습으로 나옴. 카메라 고정 | 가려진 뒤 다른 물체/색으로 등장, 이동 경로 역전, 기둥을 관통 |
| S03 상품형 장면 | 글자 없는 크림색 카드가 파란 무지 책 위에 놓인 가상 제품 모형. 상표·실제 상품·유명인 없음 | 카드·책 두 요소가 구분되고 제품 가장자리가 온전함 | 카메라가 천천히 접근. 책·카드의 형태와 위치 관계 유지. 말소리 없음 | 가짜 상표·문자·가격 생성, 책 장수가 급변, 과한 컷·손·얼굴 등장 |

프롬프트의 한국어 원문을 기본 입력으로 고정한다. 특정 모델이 영어 프롬프트만 공식 지원하면 그 모델은 한국어 직접 입력 시험과 분리한다. 사전에 고정한 영어 번역본을 쓰는 보조 시험으로만 비교하고 번역 시간·비용을 기록한다. 모든 모델에 매번 다르게 번역·보정해 준 뒤 같은 조건이라고 부르지 않는다.

### 한국어 텍스트·도표는 별도 시험

동일 배경에 다음 문구를 최종 HTML/SVG 레이어로 합성한다.

- 제목: `자료를 콘텐츠로 바꾸는 세 단계`
- 단계: `수집 → 검토 → 제작`
- 보조 문구: `승인 후 다음 단계로 이동합니다.`

기대 출력은 글자 누락·오타 0개, 지정된 읽기 순서, 16:9/9:16/1:1에서 안전 여백 유지다. 이는 최종 합성 파이프라인의 통과 조건이다. 이미지 모델 자체의 글자 생성 능력을 시험하려면 별도 트랙으로 원본 출력만 검사하고 합성 후 결과와 섞지 않는다.

## 6. TTS 공통 한국어 20문장

아래 문장은 음성 합성 시험을 위해 새로 쓴 문장이다. 제공자 고유 감정 태그·SSML을 넣지 않은 기본 트랙이며, 특정 인물의 음성을 복제하지 않는다. 각 제공자가 합법적으로 제공하는 기본 음성 또는 별도 동의가 확인된 음성만 선택한다.

| T16 | 블로그에는 설명을, 뉴스레터에는 요약을, 영상에는 장면을 담습니다. | 병렬 문장 리듬·동사 누락 없음 |
| T17 | 같은 입력을 사용하되, 화면 크기에 맞게 배치를 바꿉니다. | 대조·조건 표현의 자연스러움 |
| T18 | 화면에 보이는 문구는 시험용이며, 실제 성과를 뜻하지 않습니다. | 부정문 의미를 반대로 읽지 않음 |
| T19 | 안녕하세요.
오늘은 짧게 정리하겠습니다.
마지막에는 사람이 확인합니다. | 실제 입력에서 `\n`을 줄바꿈으로 변환; 줄바꿈을 말로 읽지 않음 |
| T20 | 자세한 출처는 설명란에서 확인해 주세요. 들어 주셔서 감사합니다. | 마무리 문장·긴 침묵·조기 종료·불필요한 추가 발화 없음 |

T04~T12의 숫자·고유명 읽기는 테스트 전에 허용형 사전을 승인한다. 사전에 없는 발음이 나왔다고 즉시 오답으로 확정하기보다 사람이 의미 보존 여부를 검토한다. 결과를 본 뒤 해당 모델에만 유리한 허용형을 추가하지 않는다.

### 음성 비교의 공정성

- 모든 후보에서 같은 원문을 쓴다. 같은 사람의 음성이 아닌데 완전히 같은 음색이라고 전제하지 않는다. `model_id + voice_id + language + speed + instruction` 조합의 결과로 기록한다.
- 후보 이름·가격을 숨기고 재생 순서를 바꿔 듣는다. 가능하면 두 명이 독립 평가하고, 한 명이면 개인 선호 평가임을 표시한다.
- 청취용 볼륨은 같은 기준으로 맞추되 원본 오디오도 보존한다. 합성기 자체의 소리와 후처리 품질을 구분한다.
- ASR 재전사는 오독을 찾는 보조 도구다. 재전사기의 오류를 TTS 오류로 단정하지 않고 숫자·고유명·부정문은 사람이 다시 듣는다.
- 기본 트랙과 감정 태그·스트리밍·목소리 복제 등 고유 기능 트랙은 분리한다. 지원하지 않는 태그를 그대로 읽게 만든 뒤 품질이 낮다고 평가하지 않는다.
- 모델/음성의 한국어 지원과 이용 라이선스가 확인되지 않으면 생성 시험에 넣지 않고 `not_eligible_unverified`로 남긴다.

## 7. 측정 항목과 기대 출력

### 고정 통과 조건

| 영역 | 통과 조건 제안 | 기록할 증거 |
|---|---|---|
| 입력 일치 | 같은 원문·같은 참조 자산·같은 파라미터 정책 | 원문/참조/설정 해시 |
| 주장·출처 | 최종 대본의 핵심 주장과 출처 ID가 대응; 가상 시험 수치를 실적으로 제시하지 않음 | 주장↔출처 표·원고 승인 |
| 한글 합성 | 최종 레이어의 정확한 문구, 잘림·겹침·누락 0개 | 기대 텍스트·OCR 보조·사람 확인·프레임 |
| 장면 일관성 | S01~S03의 필수 물체와 관계를 유지; 중대 실패 없음 | 원본 영상·프레임 표본·실패 구간 |
| TTS | 핵심 숫자·날짜·부정문·승인된 고유명에서 의미를 바꾸는 오독 없음 | 청취 기록·ASR 대조·발음 사전 |
| 파일 무결성 | 파일 열림, 선언한 크기·길이·FPS·오디오·해시 일치 | ffprobe/렌더 로그·SHA-256 |
| 승인 | 생성·게시·쿠폰 실행 권한이 각자 승인 상태와 일치 | 승인 ID·작업 ID·비용 상한 |
| 실패 처리 | 실패·시간 초과·부분 결과가 성공으로 표시되지 않음 | 작업 상태·오류·재시도 기록 |

### 점수표는 통과 조건을 넘은 결과끼리만 사용

다음 가중치는 초기 운영 결정을 위한 제안이며 측정된 결과나 표준이 아니다.

| 트랙 | 평가 항목·초기 가중치 |
|---|---|
| 이미지 | 지시·객체 일치 35, 브랜드/참조 일관성 25, 시각 품질 20, 후편집 가능성 10, 성공 자산당 비용 10 |
| 영상 | 필수 동작/물체 일치 35, 시간적 안정성 30, 카메라/구도 15, 후편집 가능성 10, 성공 자산당 비용 10 |
| TTS | 명료도/의미 보존 45, 자연스러움 25, 호흡/억양 15, 운영 지연 5, 사용 가능한 음성당 비용 10 |
| 템플릿 렌더 | 텍스트·레이아웃 정확성 40, 동일 입력 재현성 20, 편집·유지보수성 20, 처리 시간/자원 10, 운영 비용 10 |

화려한 영상이더라도 의미 오류·오독·권리 미확인·승인 우회가 있으면 점수로 상쇄하지 않는다. 저표본 탐색 단계에서는 관찰한 평균·범위·실패 수를 제시한다. 작은 표본의 임의 백분위나 AI 심사 점수를 검증된 확률로 표현하지 않는다.

## 8. 모델 전환 기준

1. **사전 심사:** 공식 경로·모델 ID·이용 권리·계정 접근·승인된 예산을 충족한 후보만 시험한다. 문서상 미확인 모델을 유료 생성으로 확인하려 하지 않는다.
2. **1차 선별:** 이미지/영상 세 샷을 후보별 2회씩 비교하고 TTS 20문장을 같은 조건으로 확인한다. 비용이 크면 T01·T05·T10만 승인된 소규모 파일럿으로 먼저 시험한다. 각 단계는 별도 예산 승인을 받는다.
3. **기존 기본값 유지:** 중대 통과 조건을 모두 만족하고 대체 모델이 실제 편집 시간을 줄이거나 성공 자산당 총비용을 낮췄다는 증거가 없으면 기존 기본값을 유지한다.
4. **전환 후보 승격:** 핵심 항목을 악화시키지 않으면서, 사전에 승인한 비용·편집시간·품질 목표 중 하나를 일관되게 개선하면 후보로 올린다. 구체적인 개선 폭은 실행 전 운영자가 정하며 사후에 숫자를 고르지 않는다.
5. **비발행 적응 시험:** 서로 다른 승인 원고 10건에서 후보를 검토한다는 초기 계획을 둘 수 있다. 이 숫자는 일반화 보증이 아니라 운영 점검량 제안이다. 실제 생성량·예산이 승인되지 않았으면 실행하지 않는다.
6. **사람의 선택:** 비용·품질·편집 부담·정책을 함께 보고 기본 모델 변경을 승인한다. 문서 버전·설정·기존 모델 복귀 방법을 함께 남긴다.
7. **즉시 복귀:** 지원 종료·정책 위반·가격 상한 초과·중대 품질 오류가 나오면 승인된 정지 이미지/HTML 설명 템플릿 등으로 전환한다. 비싼 모델을 자동으로 추가 호출하지 않는다.

유튜브 CTR·시청 유지·HeoBrain 방문/구매 전환은 발행 후 별도 측정이다. 동일 시험 대본의 제작 점수가 실제 시청·매출 증가를 증명하지 않는다. 이번에는 공개 발행·광고·쿠폰 실험을 실행하지 않았다.

## 10. 실행 환경과 검증 범위

현재 PC의 활성 AI 작업과 별도로 승인된 시험 시간을 잡는 것이 좋다. 다른 작업이 동시에 메모리·디스크·GPU를 쓰는 상황에서 나온 렌더 속도를 도구 고유 성능이라고 단정하지 않는다. 렌더러 시험은 같은 장비·같은 소프트웨어 버전·동시 작업 1개 조건으로 하고, 원본 자산과 최종 결과를 보존한다.

이번 문서는 원본/최종 파일 체계와 검증 항목을 제안한다. 실제 실행 로그, 품질 점수, 영상, 음성, 썸네일, 사용자 성과는 생성하지 않았다.
