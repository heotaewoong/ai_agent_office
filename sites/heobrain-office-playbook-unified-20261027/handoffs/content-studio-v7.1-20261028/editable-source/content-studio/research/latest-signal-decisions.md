### S1. Genie 4 공식 발표

[Google DeepMind 발표](https://deepmind.google/blog/genie-4-a-new-generation-of-world-simulation/), 발행 2026-10-27. 읽은 부문: 기능·테스터 제공 범위·책임·현재 한계·다음 공개 계획.

### S2. Gemini 4 Argon 공식 공개 발표

[Google 공개 발표](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/), 발행 2026-10-13. 읽은 부문: 공개 범위·개발자 시작·도구를 조합한 시연·가격 각주.

개발자 유료 API와 앱/Antigravity 구독 경로를 구분해 제공한다고 안내한다. 코딩·문서·복합 작업의 공급사 사례가 있으나, 영상 결과는 Blender·Nano Banana·Omni·TTS 등과 조합한 사례이므로 Argon 자체의 영상/음성 생성 API를 증명하지 않는다. 공개 모델의 소개 단가는 입력/출력 100만 토큰당 2/10달러이며 2026-11-30 소개 기간 종료 뒤 4/20달러라고 안내한다. 실제 계정 가격·Cloud 경로 견적·세금·가용 한도는 확인하지 않았다. 기능 수치와 고객 인용은 독립 검증 결과로 채택하지 않는다.

### S3. Argon 공식 API 개발 가이드

[Google Cloud 개발 가이드](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/guides/gemini-4-argon), 갱신 표시 2026-10-26 UTC. 읽은 부문: Quickstart·필수 API 규칙·이전·개발자 검사표·알려진 문제.

`gemini-4-argon` 모델 ID와 인증한 Cloud 프로젝트의 호출 예제가 있다. 텍스트 입력/출력·구조화 응답, 영상 이해 경로를 확인했다. 전체 입력+출력 한도는 1,048,576토큰이며 단건 출력은 스트리밍 65,536, 비스트리밍 직접 HTTP 32,768 기본 한도가 있다. 긴 출력은 continuation과 `v1beta1` 조건을 확인해야 한다. `thinking_budget`·`MINIMAL` 등 기존 옵션은 그대로 이전할 수 없다. SDK의 자동 continuation은 추가 요청·누적 과금까지 고려해야 한다. 이 문서는 Genie 4 API의 제공 근거가 아니며 모든 입력 MIME/출력 모달리티 표를 대체하지 않는다.
