## 1. 기존 설계와 이번 표본의 관계

기존 `2026-10-27_YouTube_선택채널_학습비서_설계.md` 본문을 읽었다. 해당 설계에는 확정된 개별 채널 명단이 없고 직접 등록·선택 모음·구독 목록의 선택적 가져오기·과거 링크 후보 제시 방법이 있다. 따라서 이 문서의 4채널은 **이번 조사 후보**이며 사용자가 이미 구독/학습 대상으로 선택했다는 뜻이 아니다. 기존 설계 원문과 개인 운영 경로는 이 문서에 포함하지 않는다.

기존 경계를 유지한다.

- 채널·재생목록·영상 1편과 자동 처리 설정은 서로 다르다. 후보 조사는 신규 채널 추적이나 전수 처리의 승인이 아니다.
- 제목·설명 확인은 영상 본문 학습과 다르다. 공개 자막 UI, 허용한 텍스트, 실제 시청, 실습 재현을 각각 기록한다.
- 타인 영상 편집 권한 없이 `captions.download`로 자막 전체를 가져올 수 있다고 전제하지 않는다. [공식 자막 다운로드 조건](https://developers.google.com/youtube/data/reference/rest/v3/captions/download)
- 작성자 주장·외부 공식 확인·우리 편집 가설·실제 실험 결과를 구분한다. 이번에는 마지막 항목이 없다.

## 3. YB01 — 조코딩: 결과물을 중심에 둔 긴 강의와 분할 목차

- **공식 채널:** [조코딩 JoCoding](https://www.youtube.com/@jocoding). 본인 [공식 소개](https://jocoding.net/about/)가 이 채널과 아래 무료 통합본을 연결한다.
- **대표 영상:** [이 영상이 당신 인생을 바꿉니다. 바이브 코딩 1인 창업 3시간 통합본](https://www.youtube.com/watch?v=P3jFI-VpyLg). 공식 소개의 무료 강의 링크를 실제 열어 YouTube 제목과 영상 ID를 확인했다.
- **공개 소개에서 관찰:** [작성자 강의 페이지](https://jocoding.net/courses/ai-product-builder/)는 하나의 통합본과 주차별 목차를 병행하고, 기획·개발·유입·AI 기능·결제·운영을 단계로 나눈다. 일부 목차는 멤버십으로 표시된다. 회원 본문은 열거나 수집하지 않았다.
- **관찰하지 않은 것:** 영상 전체, 실제 화면 시연, 코드, 시청 유지율, 수강생 성과, 현재 도구 호환성. 소개의 수익·속도 표현을 HeoBrain 성과의 근거로 사용하지 않는다.
- **편집 가설:** 독자가 얻을 결과 한 가지와 중간 산출물을 먼저 제시하고, 긴 실습은 같은 입력/완료 기준을 공유하는 단계별 안내로 나누면 시작 위치를 찾기 쉬울 수 있다. 이는 목차를 보고 세운 가설이며 영상의 실제 연출을 관찰한 결과가 아니다.
- **HeoBrain에 독립 적용:** ‘권한 있는 문서 2쪽→근거 카드 3개→읽기 쉬운 글 1편’처럼 작은 작업을 정하고, 입력·추출·검토·출력·실패 복구를 자체 자료로 보여 준다. 타인의 강의 문구·코드·화면·회원 자료는 가져오지 않는다.
- **첫 수용 검사:** 새 작업자가 자체 원고의 목차만 보고 필요한 준비물·중간 결과·성공 검사·막혔을 때 행동을 찾는지 확인한다. 현재 결과는 미실험이다.

- **HeoBrain에 독립 적용:** 새 총괄 에이전트를 추가하기 전에 자체 테스트 입력→정해진 처리→검토 대기 결과를 보여 준다. 자동 판단이 필요한 부분에만 모델을 두고, 실제 메일·게시·쿠폰은 호출하지 않는 테스트로 시작한다.

## 8. 수집·측정·배포에서 유지할 조건

1. 조사 후보를 등록할 때 사용자 선택과 확인된 채널 ID를 별도로 확인한다. 이번 문서의 handle을 검증된 channel_id로 바꾸어 쓰지 않는다.
2. 공개 제목/설명·허용한 본문·자체 노트를 분리한다. API 데이터 수집을 구현하면 현행 갱신·보존·철회 규칙을 따로 적용한다. [YouTube Developer Policies](https://developers.google.com/youtube/terms/developer-policies)
3. 조회수와 게시 시각을 나중에 수집하더라도 관측 시각을 남긴다. 독립 근거 없이 채널 점수·예상 매출·떡상 확률로 변환하지 않는다.
4. ⓪ 기획 → ① 원고 → ② 산출물 출고 → 필요한 경우 ③ 뉴스레터/홍보 회차를 보존한다. 로컬 ZIP과 외부 게시·발송 성공을 구분한다.
5. YouTube 구독·조회·좋아요·댓글 보상으로 쿠폰을 지급하지 않는다. 상품 가격·할인·기간은 확인한 오퍼와 거래 서버가 검증하며, 이번 조사로 그 권한이나 예산이 생기지 않는다.
6. 유료 모델/API·새 계정·실제 발행을 실행하기 전에 현재 작업의 권한·비용·입력 권리를 확인한다. 이번 문서의 추천은 지출 승인이 아니다.

## 9. 접근 한계와 제외한 근거

- YouTube의 여러 채널/영상 페이지에서 제목 외 본문을 확보하지 못했고 일부 요청은 throttled로 끝났다. 재생·우회·쿠키 사용·전체 다운로드를 하지 않았다.
- 조코딩 MCP 강의 소개도 읽었지만 연결 학습 페이지는 로딩 문구만 반환했다. 해당 영상 본문을 확보했다고 세지 않았고 4개 대표 표본의 내용을 늘리는 근거로 쓰지 않았다.
- 오늘코드 채널 URL은 열렸지만 영상 목록 본문을 확보하지 못해 표본 채널 수에 포함하지 않았다.
- 검색에 나타난 재게시·AI 요약·순위·추정 수익 사이트의 설명과 수치는 최종 관찰 근거로 사용하지 않았다. n8n staging 페이지 대신 운영 공식 블로그의 실제 영상 링크를 근거로 사용했다.
- 표본은 편집 가설을 만들기 위한 제한 조사다. 특정 채널의 전체 지식·실제 성공 원리·모든 과거 대화·책을 학습했다는 뜻이 아니다. 실제 시청/실습이 필요한 검증은 후속 상태로 남긴다.
