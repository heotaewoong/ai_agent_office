# HeoBrain 오피스 월드

콘텐츠 오피스의 작업 상태를 우주에 떠 있는 마인크래프트식 블록 땅 위의 마을로 보여주는 정적 3D 공간입니다. 가운데 광장이 공유 기억, 돌 블록 길로 이어진 방 다섯 개가 오피스 단계입니다. 설계는 [설계서](../../docs/superpowers/specs/2026-10-28-office-world-design.md), 구현 순서는 [계획](../../docs/superpowers/plans/2026-10-28-office-world.md)에 있습니다.

승인(⓪ 기획 선택 · ① 원고 · ② 출고 · ③ 회차)은 콘텐츠 오피스 앱에서 사람이 합니다. 이 공간은 상태를 보여주기만 하며 승인을 만들거나 대신하지 않습니다.

## 로컬에서 보기

빌드 도구가 없습니다. 정적 서버로 폴더를 열면 됩니다. 파일을 더블클릭해 `file://`로 열면 `data/space.json`을 읽지 못합니다.

```sh
cd sites/office-world
python -m http.server 8080
# 브라우저: http://127.0.0.1:8080/
```

- **관제 시점**(기본): 드래그 회전, 휠 확대, 섬·뇌 클릭으로 작업 패널.
- **걷기 시점**: M 키 또는 상단 버튼. WASD 이동, Shift 달리기, Space 점프, 드래그 시선, 동료 가까이에서 E, R 카메라 복귀. 휴대폰에서는 관제 시점만 제공합니다.
- Babylon.js 7.54.0은 `vendor/babylon.min.js`에 고정 동봉합니다. 원래 CDN의 SHA-384 무결성 값과 대조했으며 Apache-2.0 라이선스는 `vendor/LICENSE-babylon.txt`에 있습니다. 외부 요청은 선택적 Google Fonts이며 실패하면 시스템 글꼴로 표시합니다.

## 데이터

`data/space.json`이 공간 투영 v1 예시입니다. 항목 모양은 설계서 6장을 따릅니다. 실시간으로 바꾸려면 같은 모양을 돌려주는 주소를 지정합니다.

### 실시간 모드

- **앱 안**: `/world/index.html?api=/api/space&embed=1` (메뉴 "오피스 월드"). 콘텐츠 오피스 백엔드의 `GET /api/space`(읽기 전용, 승인을 만들지 않음)가 투영을 돌려줍니다.
- **단독 실행**: `index.html?api=https://서버/api/space` — 다른 도메인의 단독 페이지는 지금 `/api/space`를 읽을 수 없습니다(백엔드가 앱 자신의 origin만 받습니다). 지원하는 경로는 앱 안의 `/world/` 경로이거나, 리버스 프록시로 정적 사이트와 `/api/space`를 같은 origin에서 서빙하는 것입니다.
- 또는 `index.html`의 `app.js` 앞에 `<script>window.OFFICE_WORLD_API = '/api/space';</script>`

실시간 모드는 10초마다 다시 읽고, 실패하면 마지막 상태를 유지한 채 상단에 표시합니다. 예시 모드에서만 동료가 기억을 확인하러 걷는 연출이 돕니다.

투영에는 제목·상태·담당 이름만 넣습니다. 원문, 비밀값, `database/learning-private/`·`database/class101/`·`PRIVATE` 자료의 경로는 넣지 않습니다.

## 다른 UI와 연결하기 (협업자용)

이 공간은 데이터 파일 하나만 읽는 정적 페이지라서, 어떤 백엔드든 같은 모양의 JSON을 내놓으면 연결됩니다.

1. **투영 API 만들기 (완료: `GET /api/space`, 구현은 `apps/content-office/backend/office/space.py`)** — 설계서 6장의 "공간 투영 v1" 모양으로 `GET /api/space`를 제공합니다. 예시는 `data/space.json`입니다. `stages[]`(방), `agents[]`(동료), `events[]`(자막), `flows[]`(길 위 흐름), `brain`(중앙 기억)만 채우면 됩니다. 방 수·이름·색은 데이터가 정하므로 코드 수정이 필요 없습니다.
2. **주소 지정** — 페이지를 `index.html?api=https://내-서버/api/space`로 열거나, `app.js` 앞에 `window.OFFICE_WORLD_API`를 넣습니다. 다른 도메인이면 그 API에 CORS 허용이 필요합니다.
3. **내 화면 안에 넣기** — `<iframe src=".../office-world/index.html?api=..." allow="fullscreen">`로 임베드할 수 있습니다. 방 패널의 "오피스에서 열기"는 각 `stages[].url`로 새 탭을 엽니다.
4. **상태 조회·제어** — 페이지 전역 `window.__officeWorld`에 `space`(현재 데이터·선택), `controls`(`focusStage`, `enterStage`, `exitSpace`, `setView`), `hud`(`openStage`, `closePanel`)가 있습니다. 같은 origin에서 iframe의 `contentWindow.__officeWorld`로 접근할 수 있습니다. 공개 계약은 투영 JSON이며, 이 핸들은 보조 수단입니다.

투영에 넣는 값만 화면에 나옵니다. 공간은 진행률·완료를 추정하지 않고, 승인 상태를 바꾸는 요청도 보내지 않습니다.

## EC2 배포

Nginx 정적 호스팅 예시입니다. Amazon Linux 2023 기준.

```sh
sudo dnf install -y nginx
sudo mkdir -p /var/www/office-world
sudo cp -r sites/office-world/* /var/www/office-world/
```

`/etc/nginx/conf.d/office-world.conf`:

```nginx
server {
    listen 80;
    server_name _;
    root /var/www/office-world;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }

    # 실시간 모드: 콘텐츠 오피스 백엔드의 투영 API만 노출
    # location = /api/space {
    #     proxy_pass http://127.0.0.1:8510/api/space;
    # }
}
```

```sh
sudo nginx -t && sudo systemctl enable --now nginx
```

보안 그룹에서 80(HTTPS를 쓰면 443)만 엽니다. HTTPS는 ALB 인증서나 certbot을 사용합니다. 투영 데이터에 비공개 정보가 없을 때만 공개 주소에 올립니다. S3 정적 웹 호스팅이나 CloudFront에 올려도 같은 파일이 그대로 동작합니다.

## 검증

```sh
node --check sites/office-world/app.js
```

화면 검사는 `apps/content-office/frontend`에 설치된 Playwright Chromium으로 페이지를 열어 콘솔 오류, 섬 카드 5개와 뇌 카드, 시점 전환, 패널 열기, 1366×768·390×844 가로 넘침을 확인합니다. 카드·자막에 "게시됨"·"자동 게시" 문구가 없어야 합니다.

## 2026-10-28 궤도 초원 업그레이드

### 현재 구현

- 초원 반경 68m(저사양 모드 54m), 3개 궤도 도시·거대 궤도 링·공중 철도·행성·오로라·비행선·4개 부유 초원은 외부 이미지 없이 코드로 독립 제작했습니다. 기존 다섯 부서·공유 기억·걷기·달리기·점프·상호작용을 유지합니다.
- 정적 조형은 재질별로 병합하고 블록 지형은 thin instances로 그립니다. `?quality=low`는 후처리/그림자를 줄이며, 움직임 줄이기 설정에서는 비행선과 배경 애니메이션을 정지합니다.
- ‘오피스 탐험’에서 부서와 공유 기억을 처음 열 때마다 20 XP를 얻습니다. 현재 등록한 공간을 모두 둘러보면 120 XP입니다. 점수는 이 브라우저의 localStorage에만 저장하며 실제 업무 완료·수익·AI 성능을 뜻하지 않습니다. 새 API에서 부서 구성이 바뀌면 현재 공간에 해당하는 방문만 집계합니다.
- 배포용 예시는 ‘예시 데이터’를 표시하며 기억 절수·출처수는 0입니다. 예시의 업무·동료 상태는 실행 연결을 증명하지 않습니다. 예시 패널은 플레이북의 관련 단계로 이동하고, 실제 API를 붙인 앱에서는 기존 앱 이동/승인 계약을 사용합니다.

### 이번에 검증 완료

`node --check app.js`, 고정 Babylon 번들의 SRI 대조, 실제 Chrome 렌더링·부서 패널 열기·20 XP 반영 및 새로고침 후 보존을 확인했습니다. 앱 정적 라우트의 고정 번들/라이선스 제공은 `world-files.test.ts`에서 검사합니다.

### 계획/제안

실제 업무 완료 이벤트를 게임 보상으로 연결하려면 서버가 검증한 완료·품질 기준을 사용해야 합니다. 탐험 XP를 업무 보상으로 자동 전환하지 않습니다.

### 미구현/차단

Sites의 정적 배포 자체는 로컬/EC2 에이전트 실행 연결이 아닙니다. 실제 자동화는 같은 origin의 `/api/space` 및 기존 앱 API/인증이 필요합니다. macOS 하드웨어에서 실행한 검증은 없습니다. 휴대폰은 현재 관제/패널 탐험을 제공합니다.


## 지상 초원과 공중 팀 대지

현재 구현은 폭 1,600m의 지상 초원(높이 약 -85m)과 다섯 실제 업무 단계·공유 기억을 놓은 공중 팀 대지(높이 0m)를 분리합니다. 지상 가장자리는 9km 지평선 평면과 연무로 이어집니다. 실제 보행 범위는 양 축 -780~780m입니다. 8m 지형 셀 40,000개를 thin instances로 표시하며 모바일/저사양은 16m 셀 10,000개를 사용합니다.

첫 화면은 지상 관제입니다. ‘우리 팀 오피스로’ 버튼으로 상층을 보고, ‘지상 초원으로’로 내려옵니다. 포털과 그 사이의 수직 승강 빛기둥도 클릭해 이동할 수 있습니다. 걷기 모드에서 포털 9m 안의 E는 반대 층으로 이동합니다. 층 전환은 플레이어 위치·높이·충돌 지형·카메라를 함께 바꿉니다. `?layer=office`는 상층 관제로 시작하며 `?resume`이 있을 때만 저장한 걷기 설정을 복원합니다.

좁은 화면에서는 공간 좌표에 겹치는 작업 카드를 사용하지 않고 ‘부서 5곳·공유 기억 보기’의 가로 스크롤 목록에서 부서를 엽니다. 지상에서 부서를 선택하면 상층으로 전환해 관련 패널을 엽니다. 업무 API와 승인은 기존 계약을 유지합니다.

높이 범위·인접 셀의 1m 이하 계단은 두 품질 모드에서 137,091개 assert로 확인했습니다. 층 전환 함수의 지상/상층 위치·카메라·키 초기화·모바일/잘못된 층 방어도 자체 검사했습니다. 실제 화면 검수 및 게시 여부는 작업 영수증에서 별도로 확인합니다.


## 미래도시·교통 시각판

현재 구현: 지상 중앙을 평탄하게 정지하고 방사 대로 6개·순환로 2개·지상 건물 26개·고가 트램·공원·에너지 필드를 독립 도형으로 구성했습니다. 공중 실무 단지는 흙/잔디/나무를 제거한 높이 0m 금속·세라믹 플랫폼이며, 5개 업무실·공유 기억·후면 타워·스카이브리지·하부 반중력 엔진으로 구성합니다. 도로 교차부는 가장 높은 표면을 보행 높이로 사용하고 지상 포디움/랜드마크 및 상층 외곽 타워는 단순 도형 충돌로 피합니다.

교통은 실제 업무와 별개인 장식 연출입니다. 일반 품질에서 순환도로 호버차 10대·비행차 4대·셔틀 항공기 2대·독자 설계 우주순양함 1대를 재사용 geometry/하드웨어 인스턴스로 그립니다. 저사양은 일부 차량 수를 줄입니다. 교통 버튼으로 이동을 멈출 수 있고 동작 줄이기 설정에서는 정지합니다. 불빛은 점멸시키지 않습니다.

이번에 검증 완료: JS 구문, 도로/순환로 교차 높이(-82.71m), 포털 광장 높이(-82.625m), 계획한 25개 주요 건물 포디움과 주도로의 표본 교차 0건, 타워 충돌·포털 여유·64각 상판 경계 여유·카메라 끝 포즈·교통 정지/재생 자체 검사를 통과했습니다. 상판 아래 hull 상면은 -0.3m로 분리해 정확히 겹치던 두 표면을 제거했습니다. 실제 브라우저 시각검수와 게시 결과는 부모 작업 영수증으로 별도 기록합니다.

계획/제안: 도시 장식을 실제 업무 성과나 엔진 실행 상태로 사용하지 않습니다. 미구현/차단: 장식 트램·차량은 실제 교통 서비스가 아니며, 오피스 API 연결/인증 검증은 별도입니다.


## 재질·건축 디테일과 탑승 제어 API

건축에는 금속성/거칠기를 구분한 PBR 재질과 자체 생성 32/64px 반사 큐브를 사용합니다. 외부 HDR·사진·새 라이브러리를 가져오지 않습니다. 금속/석재의 미세 표면과 단일 상판에 그린 포장도면, 낮은 조경 포켓 5개·벤치·입면의 깊이/발코니를 보강했습니다. 상판은 높이 0m, hull 상면 -0.3m, 64각 경계를 유지하고 포장 그림을 별도 공면으로 올리지 않습니다. 조경 포켓은 업무 인계 동선 사이에 배치하며 기존 전망 지점(42,0)은 열어둡니다.

`controls.setVehicleSpeed(speed)`는 유한한 0~36m/s만 받으며 성공 여부를 boolean으로 돌려줍니다. 0은 하차, 양수는 지상에서만 허용하며 상층으로 전환하면 0이 됩니다. 현재 값은 `controls.vehicleSpeed`입니다. 차량은 점프하지 않고 0.35m 이하 이동 조각과 2.2m 충돌 여유를 사용합니다. `controls.enableTouchWalk(true)`로 명시적으로 휴대폰 걷기를 허용할 수 있고 false이면 입력을 지우고 관제로 돌아갑니다. 실제 포획/보상/차량 소유와 표시 모듈은 별도 코드가 담당하며 이 API가 업무 성과를 만들지 않습니다.

구문 검사와 속도 입력/층 제한·차량 벽 정지·점프 억제·앉은 자세·터치 허용 자체 검사를 통과했습니다. 재질의 실제 브라우저 표현과 놀이 모듈 연동은 별도 화면 검수 결과를 따릅니다.


## 차량을 골라 무료 시승

화면 아래의 **차량 골라 무료 시승**에서 스카우트 호버카 또는 노바 GT를 고르고 **무료 시승 시작**을 누릅니다. 포획·크레딧·차량 구매 없이 지상 걷기 시점으로 이동해 선택한 차에 탑승합니다. WASD로 운전하고 드래그로 시선을 돌리며 V 또는 하차 버튼으로 내립니다. 탑승 중에는 차량을 바꿀 수 없으므로 하차한 다음 다시 선택합니다.

포획 도감·크레딧·보유차 컬렉션은 기존 로컬 저장을 그대로 사용합니다. 무료 시승은 포획 보상을 주거나 크레딧을 쓰거나 소유권을 새로 등록하지 않습니다. 차량 선택만 같은 저장의 selected에 보존합니다. 모바일은 같은 시승 버튼과 화면의 방향 버튼을 사용합니다. 실제 기기/공개 주소 검수 결과는 배포 영수증과 구분합니다.


## 간편 관제·환경 설정

상단에는 생활 비서·콘텐츠 자동화·개발·옵시디언·주식 팀 이름을 접지 않고 표시합니다. 번호·색은 건물 위 이름표와 같으며, 누르면 공중도시의 해당 부서 위치와 기존 업무 패널을 엽니다. 휴대폰은 세 열로 줄바꿈합니다. 이 바로가기는 기존 공간 관람 동작을 이용하며 새 업무 지시나 승인을 만들지 않습니다.

상단 동료 목록은 같은 API 투영의 이름·업무·상태·원본 갱신시각을 보여줍니다. 검색/도움·오류 필터와 도움 버튼은 관찰 위치만 바꾸며 승인이나 업무를 실행하지 않습니다. 미인식 상태는 상태 미확인으로 표시하고, 읽기 실패에는 마지막 데이터와 연결 지연을 표시합니다.

환경에서 가볍게/선명하게 화질을 선택하고 배경 움직임을 줄일 수 있습니다. 화질 변경은 URL의 api를 보존해 다시 열며 기존 포획/보유차 기록은 유지합니다. 지상·공중팀·우주순양함 전망은 카메라 관람이며 게임 체크포인트 완료를 만들지 않습니다.

저사양 DPR을1로 제한하고 동료 목록/숨김 탭에서는3D 렌더 루프를 멈춥니다. 이동/차량 충돌은 매 프레임 유지하고 HUD는최대15Hz·미니맵은최대5Hz로 갱신합니다. 실행 중 마커는 점멸 대신 고정 상태색을 사용합니다. 성능 수치는 설계상 상한이며 실제FPS 향상·Mac/휴대전화 성능 통과는 별도 검증이 필요합니다.


## 업무 화면과 탐험·무료시승

게임 조작은 상단 탐험·무료시승 한 버튼으로 엽니다. 한 창에서 무료 시승/도시 탐험/포획·보유차를 선택합니다. 기존 조작 요소를 이동해 재사용하므로 탐험·차량 저장이나 무료 시승 조건은 바꾸지 않습니다. Esc로 닫고 원래 버튼으로 돌아오며, 창을 연 동안 이동 키를 멈춥니다. 시승·탐험 시작에 성공하면 창을 닫아 시야를 확보합니다. 업무·동료·건축 도구를 열 때도 겹치지 않도록 접습니다. 새 3D 장면·렌더 루프·외부 의존성은 추가하지 않습니다.


## Blender 입구의 근거리 상세 모델

선명하게 화질에서 카메라가 공중도시 입구38m 안으로 들어오면 자체 Blender v2 자산을 한 번 읽습니다. 상세 모델이 준비된 뒤 기존 조형을 숨기고,52m 밖이나 지상으로 이동하면 기존 조형을 다시 표시합니다. 저화질은 자산 요청/근접 검사 observer를 추가하지 않습니다. 실패하면 기본 모델을 유지하고 매 프레임 재시도하지 않습니다. 기존 통로/승강기/충돌/저장은 변경하지 않습니다.

Blender4.5.15에서 자체 제작한 원본 GLB(SHA256 4eb3370839e30e33c637f01ef490f4d45136127ff6adff1d45b847fb9212ece6)를 Babylon7.54 native scene JSON으로 변환했습니다. assets/arrival-detail-v2.json은4메시·4재질·5076삼각형/텍스처0의 자체 자산이며 외부 모델/브랜드 자산을 포함하지 않습니다. 기존 Apache-2.0 Babylon core의 serializer/parser를 재사용해 새 glTF loader를 운영에 설치하지 않습니다. 변환 시에만 공식 loader7.54를 사용했습니다. 원본324삼각형보다 복잡하므로 FPS 개선으로 세지 않습니다. 원시JSON622007B, 로컬gzip참고75042B(서버 실제전송량은별도).

제거 시 index.html의 arrival-detail.js 연결과 app.js의 arrivalArchitecture 참조/quality 노출을 되돌린 뒤 모듈/자산/검사를 제거하면 기본 조형으로 복귀합니다. 승인/업무 실행/API 정책에는 영향이 없습니다.
