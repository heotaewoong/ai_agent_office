# HeoBrain 콘텐츠 자동화 — 통합 인계·구현 문서

작성일: 2026-10-29 KST. 작성: Claude Code(김택근 세션). 대상: 이 저장소와 EC2를 이어받아 구현할 개발자와 AI 작업자.

이 문서는 허태웅 님의 Notion 기획서, Excalidraw 설계 보드, 경쟁사 분석 PDF, 개발자 통합인계서(10/29), Hermes 개발 자동화 계획(10/28), 카카오톡 목표 구조도, 그리고 이 저장소의 현재 코드·EC2 실제 상태를 한 문서로 합친 것이다. 저장소에 커밋되므로 비밀값, 로그인 정보, 협업 보드의 편집 링크, 개인사 원문은 넣지 않았다.

## 1. 한 줄 결론

HeoBrain은 "읽으면 외워지는 자료, 외웠는지 확인해 주는 AI"로 좁힌 학습·생산성 플랫폼이다. 콘텐츠 자동화는 글을 대량으로 뿌리는 공장이 아니라, 사람이 승인한 원고 한 편에서 블로그·영상·카드·자료를 독립 제작하고 올바른 계정에 도달했는지 증거로 남기는 편집 통제실이다.

- A축 학습·시험 준비(편입·자격증·오픽·AWS SAA 등), B축 개인·업무·콘텐츠 생산성.
- 사업 목표: 월 결제 매출 100만 원 검증. 성과가 있다는 뜻이 아니라 검증 목표다.
- 승인은 사람이 한다. ⓪ 기획 선택 · ① 원고 · ② 출력별 출고 · ③ 뉴스레터 회차. 에이전트는 승인을 만들지 않는다.
- 추가 결제 0원이 기본값. 유료 호출은 승인① 이후, 예약→정산→불명 장부로만 일어난다.

## 3. 브랜드 보이스와 금지 사항

원고 생성·비평·평가·수정 모두 같은 규칙을 읽는다. 저장소의 `apps/content-office/backend/config/brand/`가 정본이다.

- 먼저 해 본 선배가 친구에게 알려주듯 짧은 해요체. 팁을 먼저, 배경은 뒤에.
- 한 문장은 짧게. 문단은 3~4줄. 소리 내 읽어 숨이 막히면 다시 쓴다.
- 비유는 한국 일상 소재. 경험담은 "저"로 말하되, 실제 본인 경험이 없는 1인칭 합격담·후기·절감 시간은 만들지 않는다. 필요하면 `[사용자 경험 입력 필요]`로 비운다.
- 쓰지 않는 것: 줄표(—), "~라고 생각합니다" 반복, 번역투 대구, "결론적으로·다양한·효과적인" 같은 뻔한 연결어, 과장 광고("무조건 합격", "3일 완성", "이것만 보면 끝"), 근거 없는 "뇌과학으로 입증", 훈계("포기하지 마세요").
- 주장은 `본인 경험 / 출처 있는 사실 / 가설·제안 / 미확인`으로 구분한다.
- 학습 축 기본 흐름: 개념 → 연상·설명 → 스스로 회상 → 짧은 퀴즈 → 해설 → 다음 복습 행동. 생산성 축: 실제 문제 → 입력 → 과정 → 결과 → 검수 → 실패 복구.

## 6. 보드·Notion 대조에서 나온 추가·수정 항목

Excalidraw 보드에 붉은 메모로 남긴 것과 같다. 괄호는 이번 구현 범위.

1. 기획 전 독자 브리프 3칸: 누구에게, 어디서 막히는지, 지금은 뭘로 해결하는지. (구현)
2. 독자 프리셋: AI 입문자 하나 → 오픽·정보처리기사·편입·생산성 자동화 등. (구현)
3. 글 쓰는 규칙을 프롬프트와 결정적 검사에 반영: 해요체, 줄표 금지, 번역투 금지 등. (구현)
4. 본인 글 예시 1~2개를 프롬프트에 넣기(문체 예시 유형). (후속)
5. 시험 일정 캘린더로 시의성 점수. (후속)
6. 독자 질문 수집(홈페이지·댓글·DM) → 기획 입력 유형. (후속)
7. 카드뉴스 6~8장 출력 형식과 넘침·오탈자 검수. (후속)
8. 퀴즈 생성: 승인 원고 → 4지선다 5문항 JSON. 문제만 만들고 풀기·채점은 스토어의 기존 퀴즈 도구를 쓴다. (후속)
9. X 채널 추가, YouTube 한국어·영어 채널 분리. (구현)
10. 후기 없이 믿게 하는 과정 공개형 콘텐츠(7일 암기 일지 등). (기획 항목)
11. 하지 않을 것: 퀴즈 결과 공개를 뉴스레터 구독과 묶기, 타인 영상 추출·요약 재배포, Suno 무료 음원 상업 사용, 채널 3개 미만에서 Postiz 도입, YouTube 기본 기능인 썸네일 A/B를 자체 구현.

## 11. 오너에게 필요한 결정

- 한국어 YouTube 메인 채널의 정본 주소와 channel ID.
- X 계정 주소. 각 채널의 목적·언어·공개 범위.
- 첫 기획⓪·원고①·출고②의 작업 시간과 비용 범위.
- Runway·YouTube 자격을 언제 넣을지. 넣기 전 로그인은 유지한다.
- 리드마그넷 첫 자료(예: 시험 D-30 복습 플래너)와 동의 수집 방식.
