# OpenAI 이미지 배경 제공자 설계

작성일: 2026-10-28. 상태: 설계 확정, 구현 대상.

## 목적

장면 카드와 숏폼 영상의 배경을 OpenAI 이미지 모델로 생성한다. 지금은 Pillow가 단색 배경 위에 글자만 그린다. 생성 배경은 분위기와 소재를 맡고, 제목·수치·단계 같은 한국어 글자는 지금처럼 Pillow 레이어가 위에 얹는다. 생성 이미지에 한국어 글자를 맡기지 않는다.

## 바꾸지 않는 것

- ⓪①②③ 승인 의미. 원고 승인① 전에는 호출하지 않는다.
- 유료 호출의 자동 대체 없음. 실패하면 해당 출력만 실패로 남기고 성공 자산은 보존한다. 운영자가 프로필을 `none`으로 돌리면 기존 글자 카드 방식으로 다시 제작한다.
- 기존 총 예산 10,000원 한도와 비용 장부(reserve → settle/unknown).
- 키는 환경변수 `OPENAI_API_KEY`로만 전달하고 저장소·UI·ZIP에 넣지 않는다.

## 구성 요소

| 파일 | 역할 |
|---|---|
| `office/image_provider.py` | OpenAI Images API 호출, 예약·정산, 영수증·자산 캐시 |
| `office/image_selection.py` | 운영자가 고르는 이미지 프로필 `none`(기본) / `openai-gpt-image`, CLI |
| `office/media.py` | `draw_scene`에 배경 합성, `production_contract`에 이미지 프로필 결속, `render_short`·`produce`에 배경 렌더러 전달 |
| `office/api.py` | 대시보드에 이미지 프로필 표시, 제작 요청 시 계약에 이미지 렌더러 포함 |

## 호출 계약

- 모델 `gpt-image-2.5-flare`, 크기 `1024x1536`, 품질 `medium`, PNG, `moderation: auto`, `n: 1`.
- 프롬프트는 승인된 장면의 `caption`·`visual`과 고정 스타일 문장으로만 만든다. 프롬프트에 "글자·로고·워터마크 없음"을 명시한다.
- 캐시 키 = 모델·크기·품질·프롬프트·원고 해시·업무 ID의 해시. 같은 키의 완료 영수증이 있으면 재호출 없이 재사용한다.
- 자산은 `<state>/image-assets/<key>.png`, 영수증은 같은 이름의 `.json`에 둔다.

## 비용

- 단가(2026-10-28 공식 가격표): 이미지 출력 $30/M 토큰, 텍스트 입력 $5/M, 이미지 입력 $8/M. 유효기간 2026-11-04.
- 장당 예약 200원(약 $0.10). 실제 사용량 토큰으로 정산한다. 사용량이 없거나 예약을 넘으면 결과 불명 또는 초과로 기록하고 추가 호출을 막는다.
- 업무당 하위한도 2,000원. 장면은 최대 12개이므로 한 업무에서 2,400원까지 갈 수 있으나 하위한도에서 멈춘다.
- 네트워크 오류·HTTP 오류·응답 해독 실패는 예약을 `unknown`으로 두고 자동 재호출하지 않는다.

## 합성 규칙

- 배경은 1080×1920을 덮도록 비율 유지 확대 후 중앙 자르기.
- 글자 가독성을 위해 어두운 반투명 패널을 전체에 한 번, 글자 상자 영역에 한 번 더 얹는다.
- 장면 JSON에 `drawing_source`, `background_sha256`, `background_provider`를 기록한다.

## 검증

- 네트워크 없이 가짜 전송으로 예약·정산·캐시·불명·초과·한도를 검사한다.
- 프로필 `none`이면 비용 장부와 자산 폴더가 비어 있어야 한다.
- 배경이 있을 때와 없을 때 `production_contract` 해시가 달라야 한다.
