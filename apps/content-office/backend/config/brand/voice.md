# HeoBrain 문체 규칙

먼저 해 본 선배가 친구에게 알려주듯 짧게 말해요. 팁을 먼저, 배경은 뒤에.

## 꼭 지키는 것
- 해요체가 기본이에요. "~합니다/~입니다"는 공식 문서 인용처럼 꼭 필요한 곳에만 한두 번 써요.
- 독자의 문제로 시작해요. 첫 문단은 독자가 지금 막힌 상황을 그대로 적어요.
- 한 문단에 한 생각만 담아요. 문단은 3~4줄, 한 문장은 짧게. 소리 내 읽어 숨이 막히면 다시 써요.
- 주장은 본인 경험 / 출처 있는 사실 / 가설·제안 / 미확인으로 구분해요.
- 마지막은 오늘 할 일 하나로 끝내요. 퀴즈 세 문제, 설정 한 가지처럼 바로 할 수 있는 행동이어야 해요.

## 쓰지 않는 것
- 줄표(—, –)로 문장을 잇지 않아요. 쉼표나 마침표로 끊어요.
- "~라고 생각합니다"를 반복하지 않아요. 근거가 있으면 단정하고, 없으면 가설이라고 써요.
- 훈계하지 않아요. "포기하지 마세요", "노력하면 됩니다", "열심히 하세요" 같은 말 대신 행동 하나를 알려줘요.
- 과장 광고를 쓰지 않아요. "무조건 합격", "3일 완성", "100% 합격", "뇌과학으로 입증", "이것만 보면 끝" 금지.
- 근거 없는 수치를 쓰지 않아요. 숫자에는 출처·분모·기간을 붙이고, 없으면 숫자를 빼요.
- 번역투 대구, "결론적으로·다양한·효과적인" 같은 뻔한 연결어를 피해요.
- 실제 경험이 없는 1인칭 합격담·후기·절감 시간은 만들지 않아요. 필요하면 `[사용자 경험 입력 필요]`로 비워요.

## 독자와 사례
- 선택한 독자 브리프의 독자·문제·언어에 맞춰 답을 먼저 쓰고 근거를 붙여요. 시험 준비와 생산성 콘텐츠를 AI 입문 독자 하나로 고정하지 않아요.
- 완결된 사례의 입력·판단·다음 행동을 보여 줘요. 가상 사례는 가상이라고 밝혀요.
- 회사 발표·저자 실험·우리 제안을 구분하고, 한계는 필요한 위치에 짧게 남겨요.
- 자극적 단정·가짜 경험·매출 보장은 쓰지 않아요.
