# 주문번호 없는 반품 메일, 어디까지 판단할까?

> 개선초안·기존승인과별도·미게시 | 미승인 대본 | 음성·영상 제작 전

중심 질문: **반품 의사는 분명한데 주문번호가 없으면 다음 행동은 무엇일까?**

길이 제안: 약 40~50초. 아래 시간은 편집 설계값이며 녹음·렌더링·실제 재생시간 측정은 하지 않았습니다.

| 장면 | 시간 제안 | 내레이션 | 화면 자막 | 화면 구성 |
|---|---|---|---|---|
| 1 | 0~7초 | 텀블러를 반품하고 싶은데 주문번호는 모른다는 메일. 다음에는 뭘 해야 할까요? | “반품하고 싶어요. 주문번호는 몰라요.” | 가상 메일 한 통만 보여 준다. ‘가상 예시·API 실행 아님’ 표시 유지. |
| 2 | 7~15초 | Decisions API는 조건, 선택지, 점수로 판단을 나눕니다. 이 메일에도 세 질문을 붙여 보죠. | 반품 의사? / 문의 유형? / 필수 정보? | 메일 옆으로 질문 카드 세 장을 차례로 펼친다. 기능 근거 DC1 표기. |
| 3 | 15~25초 | 예시 답은 반품 의사 있음, 유형은 반품. 상품명과 주문번호를 각 1점으로 보면 정보는 1점입니다. | 가상 판단: 예 / 반품 / 정보 1점·2점 만점 | 상품명 ‘텀블러’에 체크, 주문번호에 빈칸. ‘사람이 작성한 예시 답’ 표시. |
| 4 | 25~34초 | 빠진 주문번호를 표시해 반품 담당자에게 넘깁니다. 담당자가 정보를 보완하고 주문을 확인합니다. | 주문번호 누락 → 담당자 인계 | 같은 메일과 세 판단을 하나의 전달 카드로 묶고 ‘주문번호 확인’에 표시한다. |
| 5 | 34~44초 | 오늘 메일 한 통에 적어 보세요. 어떤 질문을 나누고, 어느 조건에서 사람이 이어받을까요? | 오늘 할 일: 질문 3개 + 인계 조건 1개 | 세 질문 빈칸 아래 ‘주문번호 누락 시 담당자 검토’라는 예시를 적는다. |

출처: [DC1 · OpenAI Decisions 가이드](https://developers.openai.com/api/docs/guides/decisions). 모든 메일·답·점수는 가상 예시입니다. 실제 API 응답 화면을 재현하거나 호출하지 않았습니다.
