## 1. Windows 네이티브 실행 보완 (49dcba9)

원작성자의 WSL 제거 커밋(a0eb77b)을 이 PC에서 검증하고 남은 문제를 고쳤다.

- 상태 폴더 경로가 99자를 넘으면 Windows 경로 한계(260자)에 걸려 산출물 저장이 실패했다. 실행 스크립트가 시작 전에 거부하고 안내한다.
- Windows 기본 음성 코드에 남아 있던 WSL 경로 변환을 지웠다. Linux에서 Windows 음성을 고르면 명시적 오류로 멈춘다.
- 테스트가 한국어 Windows 기본 인코딩(cp949)에서 깨지던 문제를 UTF-8 명시로 고쳤다. FFmpeg나 symlink 권한이 없으면 실패 대신 이유를 적고 건너뛴다.

## 2. v7.1 인계 스냅샷 정오표 (c80a86e)

원작성자가 올린 콘텐츠 스튜디오 v7.1 인계 문서(파일 84개)를 전부 읽고 코드를 임시 사본에서 실행했다. 검증 209개와 원가 검산 19개가 통과했고, 다시 만든 파일 31개가 커밋본과 같았다. 스냅샷 원문은 그대로 두고 [정오표](../sites/heobrain-office-playbook-unified-20261027/handoffs/content-studio-v7.1-20261028/ERRATA.md)에 바로잡을 점을 모았다. 도구 수 45→49, "기본안"으로 적힌 Sonnet·Eleven은 제안값이고 실제 기본값은 Gemini와 Heami/Kore, TTS 시험은 1차 20문장, 코드 감사 이후의 앱 변경 등이다.

## 3. 유료 제공자 세 가지 (2fc88fe, 60d57a4)

세 제공자 모두 같은 원칙으로 붙였다. 원고 승인① 이후에만 호출하고, 비용을 먼저 예약한 뒤 공식 사용량으로 정산하며, 실패나 결과 불명은 자동 재시도·자동 대체 없이 장부에 남긴다. 키는 실행하는 운영자가 EC2 환경 파일에 넣고, 영수증·UI·ZIP·저장소에는 기록하지 않는다.

| 제공자 | 역할 | 비용 규칙 | 켜는 방법 |
|---|---|---|---|
| OpenAI gpt-image-2.5 | 장면 배경 이미지. 한국어 글자는 로컬 레이어로 위에 얹음 | 장당 200원 예약, 업무당 2,000원 | `OPENAI_API_KEY` + `office.image_selection set --profile openai-gpt-image` |
| Runway Gen-4 Turbo / Gen-4.5 | 승인 원고에서 `clip: generated`로 지정한 장면만 5초 생성 클립 | 500원/1,200원 예약, 최대 3장면, 업무당 3,000원 | `RUNWAYML_API_SECRET` + `office.video_selection set --profile runway-gen4-turbo` |
| YouTube Data API | 출고 승인② 영상을 소유 채널에 비공개로 업로드 | 할당량만 소모 | `YOUTUBE_CLIENT_ID`·`YOUTUBE_CLIENT_SECRET`·`YOUTUBE_REFRESH_TOKEN` + API 또는 `office.youtube_delivery deliver` |

세부 설계는 `docs/superpowers/specs/`의 2026-10-28 설계서 두 개에 있다. 세 제공자는 네트워크 없이 가짜 응답으로만 검증했다. 실제 화질·비용·업로드 결과는 키를 넣은 뒤 EC2에서 한 건 돌려 봐야 확정된다.

## 4. Linux 한글 폰트 수정 (d730f7b)

EC2에서 PDF 테스트가 실패했다. PDF 생성기(reportlab)는 Noto Sans CJK의 TTC 형식을 읽지 못한다. 폰트 후보를 TrueType(.ttf)만으로 바꾸고 `fonts-nanum`의 NanumGothic을 기본으로 찾는다. 남아 있던 WSL 경로 후보도 지웠다.

## 5. EC2 준비 상태

이 AWS 계정(heobrain)에는 오하이오 리전의 인스턴스 하나만 있다. 이 서버는 원작성자 계정(ihtwa)이 n8n과 Hermes를 돌리고 있는 운영 중인 서버라서, 멈추거나 크기를 바꾸는 작업은 하지 않았다. 접속은 AWS 자격 증명으로 EC2 Instance Connect에 60초짜리 임시 키를 보내는 방식이다. 서버에 키를 남기지 않는다.

| 항목 | 상태 |
|---|---|
| 서버 | t3.small, 2 vCPU, 메모리 2GB, 스왑 4GB, Ubuntu 26.04 |
| 설치 | FFmpeg 8, fonts-nanum, python3-venv (apt), Node 24.22 (사용자 폴더 `~/.local/node`) |
| 저장소 | `/home/ubuntu/ai_agent_office`, main 최신 |
| 백엔드 | 가상환경 설치 완료, 테스트 314 통과 · 7 건너뜀 (FFmpeg 경로까지 실제 실행) |
| 프런트 | 의존성 설치, typecheck 통과, 테스트 25/25, 프로덕션 빌드 완료 |
| 서비스 기동 | 아직 안 함. 환경 파일과 음성 프로필 선택이 먼저 필요 |

빌드는 Node 힙 1.2GB·낮은 우선순위로 돌렸고 26초에 끝났다. 같이 도는 n8n·Hermes는 영향이 없었다.

주의: Ubuntu apt의 nodejs는 TypeScript 지원 없이 빌드돼 `npm test`가 실패한다. nodejs.org 공식 바이너리를 써야 한다. PATH 등록은 운영자가 직접 한다.

## 6. EC2에서 켜는 순서

```bash
export PATH="$HOME/.local/node/bin:$PATH"
cd ~/ai_agent_office && git pull --ff-only
# ~/office.env 에 GEMINI_API_KEY 와 쓸 제공자 키를 넣는다 (저장소 밖)
cd apps/content-office/backend
.venv/bin/python -m office.voice_selection set --profile gemini-kore   # Linux에는 Windows 음성이 없음
.venv/bin/python -m office.image_selection set --profile openai-gpt-image
.venv/bin/python -m office.video_selection set --profile runway-gen4-turbo
cd .. && OFFICE_ENV_FILE=~/office.env scripts/start-local.sh
```

## 6-1. 외부 공개 (2026-10-28 추가)

운영자 요청으로 2026-10-28 현재 로그인 없이 열려 있다. 앱에는 사용자 계정이 없으므로 주소를 아는 누구나 승인·제작·업로드를 요청할 수 있다. 유료 키를 넣기 전에 인증을 다시 켜는 것을 권한다.

| 구성 | 내용 |
|---|---|
| 주소 | 공인 IP 기반 `sslip.io` 호스트 이름. 별도 도메인 없이 IP로 해석된다 |
| TLS | Let's Encrypt 인증서, certbot 타이머로 자동 갱신. HTTP는 HTTPS로 넘긴다 |
| 인증 | 현재 없음. 처음에는 nginx 기본 인증을 걸었다가 운영자 요청으로 제거했다. 다시 켜려면 `htpasswd`로 파일을 만들고 사이트 설정에 `auth_basic`을 넣는다 |
| 프록시 | nginx → Next.js `127.0.0.1:3110` → `/api`는 백엔드 `127.0.0.1:8510`. 앱 포트는 외부에 열지 않는다 |
| 앱 설정 | `~/office.env`(권한 600)의 `OFFICE_PUBLIC_ORIGIN`으로 그 HTTPS 주소 하나만 허용. 세션 쿠키는 Secure |
| 확인 | 메인 화면·3D 오피스·API 200, HTTP는 HTTPS로 301, 다른 Origin의 저장 요청 403 |

알려진 한계:

- **고정 IP 없음**: Elastic IP가 없어 인스턴스를 껐다 켜면 공인 IP와 주소가 바뀌고 인증서를 다시 받아야 한다. 고정하려면 Elastic IP를 붙인다.
- **재부팅 자동 시작 없음**: 앱은 `start-local.sh`로 띄운 상태다. 서버 재부팅 뒤에는 다시 실행해야 한다. nginx와 인증서 갱신은 시스템 서비스라 유지된다.
- **작업 시간**: 수집·제작·업로드 같은 실행 요청은 운영자가 작업 시간을 열어야 동작한다. `office.session start --minutes N`.

## 7. 남은 일

- **키 준비**: Gemini, OpenAI, Runway, YouTube OAuth. 넣은 뒤 카드 1건, 영상 1건, 비공개 업로드 1건으로 실제 검증한다.
- **서버 크기**: 2GB는 영상 조립과 동시 작업에 빠듯하다. 원작성자와 상의해 올릴지 정한다.
- **디스크**: 38GB 중 26GB 사용. 19GB가 원작성자 홈이다.
- **아직 없는 기능**: 뉴스레터 회차③ 발송(동의 장부·발송 계정 필요), 상품·쿠폰(스토어 API 규격 필요), 업로드 화면 버튼(지금은 API·명령만).
