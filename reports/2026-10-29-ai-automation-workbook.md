# 반복 업무 하나를 AI와 나누는 15분 작업표

HeoBrain 자체 작성 리드마그넷 후보 · v0.1 · 2026-10-29 · 공개 검토용 초안, 사용자 효용 미검증

목표: 자동화 도구를 모두 연결하기 전에, 반복 업무 하나에서 AI가 할 일과 사람이 확인할 일을 구분한다. 15분은 권장 시간이며 절약 성과를 보장하지 않는다.

## 1. 반복 업무 하나 고르기

아래 후보 중 지금 실제로 하는 것 하나만 선택한다.

- 블로그 글의 제목·목차 초안 만들기
- 승인된 블로그 원고를 영상 대본으로 바꾸기
- 게시 전 출처·링크·표현 누락 확인하기

내 업무: ______ / 현재 소요 시간(직접 측정 또는 미측정): ______

완료하면 얻을 파일/결과: ______ / 이번에 하지 않을 일: ______

## 2. 작업 브리프 채우기

| 항목 | 직접 작성 |
|---|---|
| 누구를 위한 결과인가? | |
| 독자가 해결할 질문 하나는? | |
| AI에 줄 권리 확인 자료는? | |
| 자료에 없는 사실은 어떻게 표시할까? | 미확인으로 표시하고 질문한다 |
| 원하는 결과 형식과 길이는? | |
| 사람이 승인할 지점은? | 초안·최종 출력·실제 게시/발송을 구분한다 |

AI에 붙여 넣을 자체 작업문 예시:

> 위 브리프와 내가 제공한 자료만 사용해 초안을 작성해 줘. 확인한 사실, 내 경험, 제안, 미확인을 구분해. 없는 수치·후기·상품 기능은 만들지 마. 결과 뒤에 확인할 출처와 사람이 결정할 항목을 적어 줘. 게시·발송은 하지 마.

비밀번호, API 키, 고객 개인정보를 입력 자료에 넣지 않는다.

## 3. 검수하고 결과 기록하기

- [ ] 독자의 질문 하나에 답했는가?
- [ ] 사실·출처·가격·상품 범위를 직접 확인했는가?
- [ ] 외부 강의·문항·이미지의 권리를 확인했는가?
- [ ] 링크를 열고 실제 결과를 확인했는가?
- [ ] AI가 모르는 것을 미확인으로 남겼는가?
- [ ] 원고 승인과 게시/발송 승인을 구분했는가?
